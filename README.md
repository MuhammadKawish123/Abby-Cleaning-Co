# Abby Cleaning Co. Website

Single-page website with scroll animation, before/after sliders, reviews, booking form and FAQs.

- Open `index.html` in a browser to view it.
- To use your own scroll video, put the file next to `index.html` and set `VIDEO_SRC` in the script.
- To use real before/after photos, put them next to `index.html` and fill in `IMG` in the script.
